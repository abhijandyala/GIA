## Maintenance Rule

Documentation must be updated in the same phase that changes:

- User-visible behavior
- Architecture or state ownership
- External packages or source material
- Bundled assets
- Permissions or data handling
- Accessibility behavior
- Performance budgets
- Competition claims

Pending tests and incomplete rubric categories must remain explicitly labeled rather
than being represented as finished.
